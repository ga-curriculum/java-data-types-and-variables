## About

This module focuses on Java's primitive and basic object data types. Participants will manipulate numerical data with the `Math` class and learn about Java's implementation of `NaN`. They'll also explore the differences between primitive and object types in Java and start working with the `String` type. Finally, the topic of explicit, implicit, and parsed type conversion.
